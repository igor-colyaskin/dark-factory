# Контекст для продолжения работы над Dark Factory

Я веду pet-project под названием Dark Factory (DF) — ИИ-агенты,
которые генерируют простые веб-приложения по текстовому заказу.
Работаю с Claude в режиме "штурман + пилот": Claude анализирует,
предлагает решения, я реализую и принимаю стратегические решения.

**Версия:** v0.4 (GitHub Integration)
**Фазы 1-2 ✅**, фазы 3-8 — не начаты.
**Среда:** корп. VDI (SAP), LLM через Hyperspace (localhost:6655),
GitHub — личный аккаунт через PAT.
**Рабочий документ:** `docs/work/v0.4-github.md`

## Ключевые решения текущей сессии (6 мая 2026)

- **LLM:** Hyperspace LiteLLM (localhost:6655), не OpenRouter
- **Модели:** anthropic--claude-4.6-opus, anthropic--claude-4.6-sonnet, gemini-2.5-flash
- **Deploy:** будет Local Runner (v0.7), Fly.io под вопросом из-за корп. сети
- **Storage контракт:** `sourceUrl` (не `githubUrl`), facade НЕ создаём
  до появления второго бэкенда
- **GITHUB_PUSH:** non-blocking state — если GitHub недоступен, заказ
  завершается нормально
- **Deployer контракт (v0.7):** async-first interface
  (`deploy`, `status`, `teardown`), Local Runner резолвит мгновенно
- **Принцип модулей:** не создавать абстракцию "для проверки" — ждать
  реальной потребности. "Контракт выводится из двух реализаций, не из одной"

## Важные принципы работы

- **Agency over capabilities:** DF развивается в сторону
  "умного агента-собеседника", не "мощного генератора"
- **Маленькие шаги ради понимания:** медленнее и глубже > быстрее и поверхностнее
- **Guided decisions:** варианты с плюсами/минусами, не пустой вопрос
- **"Делай по-взрослому, если это не требует неразумных ресурсов"**
- **Дофамин важен:** скучно = сигнал переосмыслить
- **Не копи хвосты:** лучше отложить, чем сделать халтурно
- **Граница ROADMAP / Area-51:** можешь написать acceptance criteria → ROADMAP;
  нет AC, нет триггера → Area 51

## Стиль общения

- Структурированные ответы с разбором "за/против"
- Честность: "преждевременная оптимизация" / "ты прав, я ошибался"
- Развёрнутый анализ перед предложением
- Обращение на "ты", без формализма
- Русский язык (кроме кода и терминов)
