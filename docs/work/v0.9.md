## Scope

1. **Architect output questions** — вместо Draft/Release toggle: "Нужны unit-тесты? Нужна документация?" в конце clarify-раунда → `spec.generateTests`, `spec.generateDocs`
2. **Protocol question** — REST/OData2/OData4/Другое в clarify, `generateStaticFiles()` выбирает mockserver по `spec.protocol`
3. **Layout question** — m.Table/Form/Другое, Developer выбирает шаблон
4. **Unit тесты** (если `spec.generateTests = true`) — `AllTests.js`, `.nycrc.json` статические, `DataHelper.qunit.js` через LLM. DEV_CHECK для IC: запускает `npm test`
5. **README.md** — статический шаблон + подстановка из spec
6. **Confluence page** — markdown рядом с README *(блокер: нужен шаблон)*
7. **Fix** — Tester видит только 5 LLM-файлов, не видит статические
