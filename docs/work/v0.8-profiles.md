## Архитектура

**Инвариант (магнитофон):** state machine, SSE, UI, file management, GitHub push.

**Профиль (кассета):** промпты агентов, deployer, verifier. Объект конфига:

```js
// server/profiles/nodejs-app.js
export default {
  id: 'nodejs-app',
  name: 'Node.js App',
  prompts: {
    architect: () => import('../prompts/architect.js'),
    developer: () => import('../prompts/developer.js'),
    tester:    () => import('../prompts/tester.js'),
  },
  deployer: 'local-runner',  // 'local-runner' | 'none'
  verifier: 'vision',        // 'vision' | 'manifest' | 'none'
}
```

**Три точки подключения:**
1. `server/index.js` — промпты агентов
2. `server/orchestrator.js` — deployer (`executeLocalDeploy` vs skip)
3. `server/orchestrator.js` — verifier (`vision` vs структурная проверка манифеста)

**Выбор профиля:** через UI перед заказом (per-order). Профиль сохраняется в state оркестратора.

---

## Integration Card — что генерируем

**Файловая структура:**
- `manifest.json` — декларация карточки (`sap.card` schema)
- `Component.js` — UI5 Component
- `i18n/i18n.properties` — переводы
- `package.json` — зависимости card SDK

**Delivery:** нет запущенного сервера → нет Local Runner. Только GitHub-архив.

**Verifier (structural):** проверяет наличие `manifest.json` и обязательных полей:
`sap.card.type`, `sap.app.id`, namespace, destination.
`sap.card.header` и `sap.card.content` не проверяются для `type: Component` — эти поля не нужны в манифесте Component-карточек.

## Итоги Phase 5 (dogfooding)

**Найденные и исправленные проблемы:**
- Hyperspace LiteLLM режет вывод на ~8192 токенах — developer не мог вместить 11 файлов.
  Решение: LLM генерирует только 5 extension-point файлов, 8 статических пишет сервер через `generateStaticFiles(cardSlug)`.
- VerifierC давал PARTIAL для Component-карточек — `sap.card.header` и `sap.card.content` не нужны в манифесте Component-типа. Исправлено.
- `ui5-local.yaml` и `ui5.yaml` отсутствовали в выводе — добавлены как статические шаблоны.

**Результат первого прогона:**
- Заказ: "Карточка сотрудника с полями FirstName, LastName, Position, Department, destination HCM_API"
- Pipeline: ARCH → DEV → TEST → DELIVERING → DEPLOYING → VERIFYING → DONE ✅
- Верификация: PASS (все 6 чеков зелёные)
