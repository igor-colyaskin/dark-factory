# VIZ-001 — Local Sandbox Preview

**Статус:** дизайн/архитектура (сессия 2026-05-09)  
**Следующий шаг:** согласовать scope и решения ниже перед кодом

---

## Суть задачи

После успешного DEV_CHECK показывать живую карточку с mock-данными прямо в DF UI.
Пользователь видит результат не выходя из Dark Factory.

---

## Контекст и ограничения (из backlog)

- **SDK:** лежит в GitHub, нужны ~4-5 файлов (Base.controller, ErrorHandler, AuthorizationDialog.controller, CustomError). Не весь пакет.
- **Тип sandbox:** изолированный, на уровне карточки — эмуляция WZ без реальных destinations. Общий sandbox с destination dev-среды — не наш случай.
- **Потенциальные блокеры:**
  1. Лицензия: копирование SDK-файлов в dark-factory repo — нужно проверить
  2. CORS при iframe-рендеринге
  3. Lifecycle сервера (zombie processes, port management)

---

## Архитектурные вопросы для обсуждения

### 1. Где живёт sandbox-сервер?

**Гипотеза из backlog:** единый sandbox-сервер внутри DF (один экземпляр), умеет загружать любой workspace по `cardSlug`.

**Вопросы:**
- Отдельный Node-процесс или встроен в `server/index.js`?
- На каком порту? (сейчас DF = 3000, Local Runner = 3100-3999)
- Как запускается: при старте DF или on-demand (первый preview-запрос)?

### 2. Как рендерится карточка?

Варианты:
- **A) iframe в DF UI** — DF отдаёт HTML со scaffold-страницей, карточка грузится внутри iframe. Проблема: CORS, UI5 bootstrap.
- **B) Новая вкладка** — sandbox URL открывается в отдельной вкладке. Проще с точки зрения CORS.
- **C) Встроенный UI5 bootstrap в DF** — рискованно, конфликт UI5 версий.

### 3. SDK — копировать или symlink?

- Копировать ~4-5 файлов в `server/sandbox/sdk/` — просто, но лицензионный вопрос
- Symlink на реальный teamSF repo (если есть локально) — нет лицензионного риска, но зависимость от окружения
- NPM пакет (если @sapitpe доступен через VPN/корп npm) — чисто, но требует проверки

### 4. Когда показывать кнопку Preview?

- Только после успешного DEV_CHECK (`spec.generateTests = true` && все тесты зелёные)
- Или всегда после DONE, но с предупреждением если тесты не запускались

### 5. Где SDK берётся?

Нужно уточнить: GitHub URL пакета + лицензия. Без этого нельзя принять решение по п.3.

## Решения этой сессии (заполнять по итогу)

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | SDK лицензия | SDK не копируется — используются существующие стабы в `external_libs/` |
| 2 | Размещение SDK | Per-workspace стабы (уже генерировались в v0.9) |
| 3 | Метод рендера | Новая вкладка (`window.open`) |
| 4 | Sandbox-сервер | `sandbox-manager.js` — один процесс, `npm run sandbox -- --port PORT` в `workspace/` |
| 5 | Preview trigger | Всегда после DONE, если `state.currentSpec.cardSlug` существует (IC-карточки) |
