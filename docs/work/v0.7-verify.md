# v0.7 — VERIFY: рабочий документ

**Статус:** в работе
**Цель:** агент проверяет своё приложение глазами заказчика и выдаёт отчёт.

---

## Архитектура

- **VerifierA** (структурный): HTTP-проверки, HTML, роуты — быстро, бесплатно
- **VerifierB** (vision LLM): puppeteer-core скриншот + Hyperspace vision-модель
- **Compositor**: `verifier.run(url, spec) → Report` — A → B, graceful degradation при ошибке B
- **Контракт:** форма Report выводится из реализации VerifierA

Оркестратор вызывает один `verifier.run()` и не знает о внутренней структуре.
