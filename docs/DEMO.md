## Ключевые тезисы

### DF-IC + Vibe coding = полный workflow

DF-IC покрывает воспроизводимые 80%: структура карточки, маппинг полей,
mock-данные, тесты, sandbox preview — за ~1 минуту вместо ~2 часов вручную.

Для оставшихся 20% — специфика команды, нестандартные паттерны,
индивидуальные требования — вайб-кодинг на готовом скаффолде работает
быстрее и надёжнее, чем пытаться описать всё это в промпте.
Это не ограничение — это дизайн-принцип: правильное разделение труда
между генерацией и кастомизацией.
