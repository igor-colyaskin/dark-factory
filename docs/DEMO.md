# DF-IC Demo

Аудитория: тимлид + команда. Формат: показываю сам, живой диалог.

---

## Ключевой тезис

DF-IC покрывает воспроизводимые 80%: структура карточки, маппинг полей,
mock-данные, тесты, sandbox preview — за ~1 минуту вместо ~2 часов вручную.
Для оставшихся 20% — vibe coding на готовом скаффолде.
Это не ограничение — это дизайн-принцип: правильное разделение труда.

---

## Вступление

> *«В работе есть задачи, где нужно думать — и есть рутина, где работают руки.
> Казалось бы, именно там ошибиться сложнее. Но на практике — наоборот:
> как раз рутинная, воспроизводимая работа чаще всего становится источником
> ошибок из-за человеческого фактора. DF-IC создана для этого.
> То, на что раньше уходило два часа, — теперь минута. Ошибки исключены.»*

## Структура питча

```
1. Боль         «Сколько времени уходит на новую карточку с нуля?»
                Пусть назовёт цифру. Потом: «Сейчас покажу за 3 минуты.»

2. Generate     [DEMO ~5 мин] Заказ → пайплайн → sandbox preview
                Punch line: «90 секунд. Вручную — полтора часа.»

3. Clone        «Нужна вторая версия под другой backend.
                Обычно — клонируешь папку, потом час ищешь где не заменил namespace.»
                [DEMO ~2 мин] clone → чистый rename, без LLM, без ошибок
                Punch line: «Детерминированно. Без ошибок.»

4. Chronicle    «Карточка готова, правки внесены. Версии разъезжаются
                по manifest, package.json, README. Обычно — руками.»
                [DEMO ~2 мин] Chronicle tile → Generate → Apply
                Punch line: «Одна кнопка. Все файлы. Версии согласованы.»

5. Горизонт     «Сегодня — карточки. Рутинная воспроизводимая работа есть везде.»

6. Закрытие     «Это уже работает — я использую сам.
                Хочу с вашей помощью понять, в каком направлении развивать.
                Как смотришь?»
```

## Разговор

**Принцип:** не продажа — исследование вместе с аудиторией.

После demo — пауза, потом:
*«Это v1. Намеренно простое — scaffold tool, как `create-react-app`.
Хочу понять, в каком направлении это развивать.»*

Вопрос к аудитории:
*«Что вы делаете руками чаще всего — после того как карточка создана?»*

**Если звучит вопрос про Edit (из рукава):**
*«Edit — другой движок, не generation pipeline. DF дал вам 80% за 3 минуты,
оставшиеся 20% — в IDE с Claude Code, это минуты. Хочу сначала услышать
что нужно менять чаще всего — это и станет v2.»*

## Сценарии

### A — Generate с мокапом (primary, ~5 мин)

Карточка: **Eintopf** (BE response таблица — тимлид узнает).
Пишем описание → запускаем → тимлид смотрит пайплайн → Preview в sandbox.

**Фишка в заказе:** BE отдаёт смешанные нотации — `vendorId`, `name` (camelCase) и `Tier`, `Status` (PascalCase). Упомянуть: *«Дружба с BE — отдельная головная боль. Мы описали как есть — DF сам разобрался с маппингом.»* Открыть `DataHelper.js` — показать что поля правильно смаплены.

После preview: открыть `wiki.html` — *«Документация для Confluence. Вставить в Source Editor — готово.»* Открыть `README.md` — для разработчика.

*Fallback при сбое LLM: предзагенерированная карточка в My Apps.*

### B — Import → Clone (~2 мин)

**Import:** берём готовую карточку (ZIP или папка) → импортируем → появилась в My Apps.
*«Готовую карточку коллеги можно принести вот так.»*

**Clone:** клонируем только что импортированную → меняем slug.
Показываем: namespace переименован детерминированно, без LLM, без ошибок.
Punch line: *«Детерминированно. Без ошибок.»*

### C — Chronicle (~2 мин)

**Нарратив:** *«Что-то изменил, что-то копипастил — ушло 5 коммитов. Версии разъехались
по manifest, package.json, README. Обычно это ручная работа — и про это обычно забывают.»*

**Подготовка:**
```bash
cd c:/Users/C5353238/projects/dark-factory/cards/employee-directory
git reset --hard "employee-directory@0.0.1"
```

**Прогон:**
```bash
git cherry-pick demo/fix-description demo/ux-search demo/feat-phone
```
→ Показать Git Graph — 3 новых коммита. Показать теги: *«Версии в git маркированы тегами — вот они.»*
→ Chronicle tile → карточка выбрана → From: тег подставлен → коммиты видны →
New version: `1.0.1` → Generate → Apply →
Explorer: `README.md` обновился, версии согласованы везде.

Punch line: *«Одна кнопка. Все файлы. Теги в git. Без ручной синхронизации.»*

**Сброс для повтора:**
```bash
git reset --hard "employee-directory@0.0.1"
```
