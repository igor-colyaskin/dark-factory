### [TPL-002] Конвенция namespace / имя папки для IC карточек
**Источник:** устное обсуждение, сессия 2026-05-09  
**Суть:** При ручном изготовлении карточек название папки должно соответствовать namespace —
это занимает много времени и почти всегда содержит ошибки. В CARDS.md нет единой конвенции.  
**Что делать:**
1. Проанализировать CARDS.md — найти доминирующую тенденцию (namespace → slug)
2. Зафиксировать конвенцию в `docs/contracts.md` / системном промпте Архитектора
3. Если в заказе не указан slug — Архитектор выводит его самостоятельно из описания,
   показывает в Spec Review; пользователь корректирует если не нравится (не спрашивает явно)  
**Приоритет:** средний (обязательно до активного использования)

### [UX-002] Режим редактирования существующей карточки (My Apps + Edit + Import)
**Источник:** устное обсуждение, сессии 2026-05-09, 2026-05-09  
**Суть:** Реальный рабочий режим — создание карточек с нуля редко (12-16/год),
редактирование существующих — постоянно. GitHub из DF-IC убран: IC-карточка не
деплоится через DF, вывод = файлы в `cards/{slug}/`, дальше разработчик сам.

**Архитектурные решения (зафиксированы):**

1. **`workspace/` → `cards/{slug}/`** — постоянное хранилище каждой карточки вместо
   единой перезаписываемой папки. Sandbox-manager получает путь динамически.

2. **`cards-registry.json`** в корне DF:
   ```json
   [{ "slug": "my-card", "name": "My Card", "createdAt": "...", "lastModified": "..." }]
   ```
   Пишется при создании карточки. Читается страницей My Apps.

3. **My Apps страница** — список карточек из реестра: имя, дата, кнопки **Edit**,
   **Preview** (перезапустить sandbox). Кнопки **+ New Card** и **Import Card**.

4. **Edit flow (delta-режим):**
   - Пользователь кликает Edit → описывает изменение
   - Архитектор видит текущие файлы + задачу → строит **патч**, не spec с нуля
   - Developer применяет → файлы в `cards/{slug}/`
   - Delta-Архитектор — отдельный промпт, не вариация существующего

5. **Import Card** — загрузить чужую карточку в реестр:
   указать папку (zip / git clone / сетевая папка) → копируется в `cards/{slug}/` →
   появляется в My Apps → дальше обычный Edit flow.
   Сценарий: коллега в отпуске, инцидент — передаёт папку любым способом.

**GitHub:** убран из scope DF-IC полностью. Не нужен ни для создания, ни для Edit.
Коллеге для установки DF-IC нужен только AI API key.

**Приоритет:** высокий (блокирует реальное использование при >2 карточках)  
**Версия:** v0.11 (SDK-001 первым шагом, затем My Apps + Edit + Import)
