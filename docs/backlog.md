### [TPL-003] Уточнить значения spec.layout до конкретных UI5 контролов
**Источник:** UAT сессия 2026-05-10  
**Суть:** `spec.layout: "form"` и `"table"` неоднозначны — `"form"` может быть
`sap.m.SimpleForm` или `sap.ui.layout.form.Form`, `"table"` — `sap.m.Table` или `sap.ui.table.Table`.
Неточность накапливается по мере добавления новых шаблонов.  
**Что делать:** Переименовать или расширить значения layout чтобы они явно указывали контрол,
например `"simple-form"`, `"m-table"`, `"ui-table"`. Обновить architect.js и developer.js.  
**Приоритет:** средний (решить до добавления второго шаблона)

### [INF-002] Проактивный split Developer-вызова для table layout
**Источник:** UAT сессия 2026-05-10  
**Суть:** View.view.xml для table значительно больше чем для form — при многих колонках
Developer регулярно попадает на retry из-за Hyperspace ~8192 token output limit.
Retry справляется, но это лишний LLM-вызов и задержка.  
**Что делать:** По аналогии с generateTests — при `spec.layout === "table"` сплитить Developer
на два вызова: (1) manifest + DataHelper + i18n + MockDataGenerator, (2) View.view.xml отдельно.  
**Приоритет:** низкий (retry работает, блокера нет)


**Реализован:** сессия 2026-05-10 (v0.11.1 cleanup)
